# 手机能用指纹浏览器吗？

能。「指纹浏览器」的手机端从首页环境卡片进入网页。外出接到值班消息时，先选对应店铺，再用首页搜索框打开订单地址，能减少进错后台的机会。
[官网操作说明](https://zwbrowser.com/help/mobile/start/)

![手机首页的当前环境和搜索框](https://zwbrowser.com/images/mobile-guide-active-light.webp)

## 怎么判断适不适合手机值班？

拿一条测试订单，从选店、进入订单页到找到售后记录走一遍。锁屏后再回来，观察当前卡片和网页上的店名。后台如果有宽表格、悬停菜单或很小的按钮，也要在手机上实际点一次。

## 哪些工作还得回电脑或业务 App？

若流程最后需要原生 App 的相册上传，就用相应 App 验收。若需要左右并排比对两张报表，可以在电脑上完成。安装前到[官网下载页](https://zwbrowser.com/download/)选择 Android、iPhone 或鸿蒙对应入口。
